Goal: turn foundation into usable AI context.

Run only after Phase 1 is usable.

Create or update:

```txt

```

Rules:

* derive from Phase 1 only
* no new business facts
* no fake competitors
* no fake case studies
* no fake metrics
* unknown = `TBD`
* assumption must be marked
* keep docs short
* make docs useful for retrieval

Each context doc should answer:

```txt
What is this?
When should AI use this?
What rules must AI follow?
What should AI avoid?
What files is this based on?
```

After done, report:

```txt

missing foundation

next action
```
